# Smart Agriculture Monitoring and Automatic Irrigation System

## Description
Automatic irrigation system using ESP32 to monitor soil moisture, temperature, and humidity.

## Components
- ESP32
- DHT22 Sensor
- OLED Display
- LED
- Buzzer

## Features
- Automatic Irrigation
- Soil Moisture Monitoring
- Temperature Monitoring
- Humidity Monitoring
- OLED Display
- Buzzer Alert
