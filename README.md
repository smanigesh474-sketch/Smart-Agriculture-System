# Smart Agriculture Monitoring and Automatic Irrigation System

## Description
Automatic irrigation system using ESP32 to monitor soil moisture, temperature, and humidity.

## Problem Statement
Traditional irrigation methods require manual monitoring and often lead to water wastage. Farmers may overwater or underwater crops due to the lack of real-time soil condition monitoring. This project provides an automated irrigation system using ESP32 that monitors soil moisture, temperature, and humidity, and automatically controls irrigation to improve water efficiency and crop growth.

## Components
- ESP32
- DHT22 Sensor
- OLED Display
- LED
- Buzzer

## Features
- Automatic Irrigation
- Soil Moisture Monitoring
- Temperature Monitoring
- Humidity Monitoring
- OLED Display
- Buzzer Alert
